# Restaurant GUI

## Project Description

The Restaurant GUI is a Java-based application designed for a fictional restaurant that uses multithreading to handle orders in the background.
It allows users to place orders for burgers, sides, drinks, and sauces, and displays the orders in a text area.
The application features a simple and interactive graphical user interface (GUI) built with Swing.

## Features

- **Interactive GUI:** Allows users to select burgers, sides, drinks, and sauces.
- **Order Management:** Orders are processed in the background with Threads, Waiter starts chef, Chef prepares and return to waiter to display on GUI.
- **Order Display:** Orders are processed and displayed in a text area.
